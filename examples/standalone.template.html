Sysrepo oven — every YANG node at a glance

This single file is a self-contained demo covering all nodes of the oven module: configuration leaves, read-only state data, both RPCs, and the oven-ready notification. The engine and the YANG schema are embedded, so it works when opened directly in a browser (double-click), through the VS Code Live Server extension, or from any static server. Every request below is previewed, never sent.
